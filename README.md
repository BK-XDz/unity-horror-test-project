# Run or Hunt - 3D Horror Prototype

A small, single-zone 3D indie horror game prototype built in Unity. This is a personal learning project created to practice core game development mechanics.

## 🎮 Planned Features
- First-person movement and camera controls (Unity New Input System)
- Modular corridor / basement level layout
- Basic monster AI with patrol and chase states (Unity NavMesh)
- Key/Fuse collection and escape trigger loop

## 🛠️ Built With
- **Engine:** Unity (URP)
- **Language:** C#
- **IDE:** Visual Studio Community
- **Version Control:** GitHub Desktop + Git LFS

Work in progress (Initial learning phase).
